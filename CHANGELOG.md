# Changelog

## [1.0.0] - 2026-04-22

### Added
- Core domain classes (User, Expense, Category, Budget, Alert, SharedExpense)
- Simple Factory pattern (ExpenseFactory)
- Factory Method pattern (BudgetAlertService)
- Abstract Factory pattern (ReportFactory)
- Builder pattern (ExpenseBuilder)
- Prototype pattern (BudgetPrototype)
- Singleton pattern (DatabaseConnection)
- JUnit 5 unit tests for all creational patterns

### Changed
- Updated README with design decisions and pattern justifications

### Fixed
- None
## [1.2.0] - 2026-05-17 (Assignment 12)

### Added
- Service layer: `UserService`, `ExpenseService`, `BudgetService` with business logic.
- REST API controllers: `UserController`, `ExpenseController`, `BudgetController`.
- DTOs (UserDto, ExpenseDto, BudgetDto) for clean API contracts.
- Swagger/OpenAPI documentation (auto‑generated by SpringDoc).
- Unit tests for services and integration tests for controllers.

### Changed
- Updated `pom.xml` with Spring Boot Web and Swagger dependencies.
- In‑memory repositories (Assignment 11) are reused and injected into services.
