# Roadmap – Personal Expense Tracker

## ✅ Completed (Assignments 9–13)
- Domain model (User, Expense, Budget)
- In‑memory repositories
- Service layer with business logic
- REST API (Spring Boot)
- CI/CD pipeline with GitHub Actions (tests + JAR artifact)
- Branch protection rules

## 🔜 Short‑term (next 3 months)
- [ ] Add **database persistence** (PostgreSQL) using Spring Data JPA.
- [ ] Implement **user authentication** (JWT) and role‑based access.
- [ ] Build a **frontend dashboard** (React) that consumes the REST API.
- [ ] Add **export to PDF** (iText or similar) for monthly summaries.
- [ ] Improve test coverage to >85%.

## 🚀 Long‑term (6–12 months)
- [ ] **Mobile app** (Flutter) for on‑the‑go expense entry.
- [ ] **Recurring expenses** (e.g., monthly subscriptions) with automatic creation.
- [ ] **Currency conversion** (multi‑currency support, with ZAR as base).
- [ ] **Receipt image upload** and OCR (optical character recognition) for automatic amount extraction.
- [ ] **Deploy to cloud** (AWS / Azure / Heroku) with HTTPS.
